# KWin Konveyor

KWin Konveyor is a modified version of KDE KWin 6.8.2.

It adds configurable appearance options to the built-in Overview effect.

## 1. Features

1. Blur Background

Controls blur behind the Overview interface.

2. Dim Background

Controls background dimming.

3. Show Desktop Bar Previews

Shows window previews in the desktop bar.

4. Show Desktop Bar Shadow

Controls the shadow behind the desktop bar.

5. Show Desktop Preview Background

Shows or hides the wallpaper inside workspace previews.

When disabled, workspace previews have a transparent background.

## 2. Compatibility

1. Based on KDE KWin 6.8.2.
2. Designed for KDE Plasma.
3. Modifies the built-in Overview effect.

## 3. Configuration

The options are available in the Overview effect settings.

Each option can be enabled or disabled independently.

Blur, dimming, and desktop preview background options can be combined.

## 4. Project Status

This is a personal KWin modification.

The changes are maintained separately from the original KDE KWin project.
