# KWin NoBlur

KWin NoBlur is a modified version of KDE KWin 6.8.2.

It adds appearance settings to the built-in Overview effect.

## 1. Features

1. Blur Background
2. Dim Background
3. Show Desktop Bar Previews
4. Show Desktop Bar Shadow
5. Show Desktop Preview Background

## 2. Installation

Clone the repository:

git clone --branch konveyor-overview https://github.com/KenHoKai/kwin-noblur.git

Enter the package directory:

cd kwin-noblur/packaging/arch

Build and install:

makepkg -si
